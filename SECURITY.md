# Security policy

The AESS generator is a static website. It runs entirely in your browser, sends nothing to a server and stores only your plate list in local storage. Its only third-party code is three.js and manifold-3d, loaded from jsDelivr at pinned versions.

## Reporting a vulnerability
Please report it privately through **[GitHub security advisories](../../security/advisories/new)**, not in a public issue. Expect a reply within a week.

## Supported versions
Only the latest release and the live site at `main` get fixes.
