      How AESS works

      Every part shares one stacking interface, so anything stacks on anything with the same footprint.

      Footprintn × grid − 0.5 mm (grid 42 mm by default), or any exact size
      Heightunits × step + 4.3 mm; each bin adds exactly units × step to a stack
      StackingA 4 mm foot drops into the bin below with 0.3 mm play. Secure, with no clicking needed
      Slide lid1.2 mm plate in rails 7.1 mm below the rim; bumps click into wall notches. Adds no height: lidded boxes still stack
      WallsLite 0.8 · Standard 1.2 · Heavy 1.6 mm; the rim is always 1.2 mm

      Print settings

      0.4 mm nozzle, 0.2 mm layers (0.28 for speed). Wall loops: 2 for Lite, 3 for Standard, 4 for Heavy. 0% infill, no supports, foot down as exported. Print the lid flat as exported.

      Bambu Studio presets

      Import once (Bambu Studio → File → Import → Import Configs…), then pick the preset that matches the part's wall. Each one is the stock “0.20mm Standard @BBL A1” with the AESS walls, 0% infill and the seam at the back, away from the branding.
